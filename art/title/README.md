# METAL SLUG X64 title artwork

Authored through image generation using the reconstructed arcade title as its
reference, at the user's request. It preserves the original industrial palette
and adds a readable 64 with Nintendo 64-era styled display lettering; it does
not use or claim to be an official Nintendo font.

`tools/pack_title_art.py` converts the full image to 320x240 with nearest-neighbor
sampling and RGBA5551 for the N64. The active title is a single adapted plate;
this does not implement the full animated arcade intro or complete first mission.
